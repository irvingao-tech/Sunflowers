# 向日葵 · 一场缓慢的绽放

以目录中提供的梵高《向日葵》图片为参考的三维互动作品。Three.js 实时生成陶瓶及 15 枝向日葵，按参考画的花头位置重建布局，区分成熟花盘、展开花瓣、低垂与背向花头。加入黄墙、赭黄桌面、双色陶瓶和程序笔触材质。正面构图参考原画，侧面及背面是三维推演，尚非逐笔复刻。花瓶中生长是艺术化表达，并非植物学模拟。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

浏览器打开终端输出的本地地址。同一 Wi-Fi 下手机可以打开电脑的局域网 IP 加端口（需允许系统防火墙访问）。不能直接双击 index.html。

## 交互

- 鼠标拖动或单指拖动旋转；滚轮或双指缩放。
- 时间轴从「02 生长」（35%）开始，移除「01 萌芽」。默认 2×，从生长到盛放约 3.25 秒；支持 0.5× / 1× / 2×。
- 先完成生长到盛放，再保持盛放让花束绕竖直轴旋转一周，最后精确回到起始角度。相机、灯光、光束和背景保持固定。默认 2× 时生长约 3.25 秒、旋转 3 秒，总计约 6.25 秒。暂停可继续；复位恢复正面，拖动时间轴取消旋转。
- 时间轴可拖动、用键盘调节，或点击三个阶段跳转。
- 环绕、视角复位、原画对照；弹窗可用 Escape 关闭。
- 桌面端点击、手机端双击向日葵画面可播放生长动画；拖动仍用于旋转视角。
- 初始显示完整花束，不自动播放；系统减少动态效果设置会关闭轻微摆动。

## 部署到 GitHub Pages

目标仓库：https://github.com/irvingao-tech/Sunflowers 。启用 Pages 并成功部署后，网址为 https://irvingao-tech.github.io/Sunflowers/ 。

1. 在 GitHub 创建仓库，将本目录的源文件（不含 node_modules 和 dist）推送到 main 分支。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. 推送 main 或在 Actions 手动运行 Deploy to GitHub Pages。
4. 成功后通过 `https://用户名.github.io/仓库名/` 访问，手机电脑共用一个网址。

已配置相对资源路径，支持仓库子路径部署。部署前可执行 `npm run build`，再用 `npm run preview` 查看生产构建。GitHub Pages 的具体可用性取决于仓库可见性及账户方案。

## 文件

- `src/main.js`：镜头、动画与交互。
- `src/artwork.js`：原画构图、模型与程序笔触材质。
- `src/animation.js`：动画时长与水平环绕计算，使用 `node --test src/animation.test.js` 验证。
- `src/style.css`：桌面及手机布局。
- `C8WrD_UW0AAT6xB.jpg`：用户提供的参考图，保留原文件。
- `.github/workflows/deploy.yml`：自动构建发布。

Three.js 随应用打包，不依赖运行时外部脚本 CDN。中文衬线字体可选从 Google Fonts 加载，失败时回退到系统字体。需要支持 WebGL 2 的现代浏览器；低端移动设备的实际帧率取决于硬件。

## 立体造型与灯光

花束深度分布约为 -1.05 至 1.12 个场景单位，花头有不同朝向；花盘前后均有体积，花瓣和叶片是封闭双层网格。材质叠加宽笔触、细刷毛和颗粒，并以凹凸贴图表现颜料起伏。花瓣按 2–3 层错位叠加，每朵 44–84 片。使用左上方暖色聚光、低强度冷色补光和背部轮廓光，强化花瓣自阴影及桌面投影；透明锥体模拟轻微空气光束。原作只有正面参考，侧后方为艺术重构。

## 背景音乐

使用用户提供的 `music/vincent .m4a`，循环播放，初始音量 35%。页面打开时会尝试自动播放；若手机浏览器拦截有声自动播放，双击向日葵画面时启动音乐。右上角音乐按钮可随时暂停或继续。音乐独立于生长动画，暂停动画不暂停音乐。音频由 Vite 随站点打包，支持 GitHub Pages 子目录地址。
